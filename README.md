# Invisible Debt Trap Analytics

This project uses data science and machine learning to detect early consumer credit risk patterns before formal payment delays appear.

## Project Aim

The aim is to build an AI-based early warning system for consumer credit rotation risk and debt carry-over pattern detection.

## Methods Used

- Data cleaning and wrangling
- Feature engineering
- Logistic Regression
- Classification Tree
- Random Forest
- Model comparison using recall and AUC

## Key Result

The Classification Tree was selected because recall was the main priority for early warning detection.
